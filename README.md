# ABVPK & Associates — Final Website

A responsive Next.js single-page corporate website for a multi-partner Chartered Accountancy firm.

## Included
- Five real partner portraits supplied by the firm, cropped/optimized for responsive cards.
- Head Office + four Faridabad branch locations from the supplementary partnership deed.
- Illustrative office photography for branch cards only. These images are explicitly labelled as illustrative and are not presented as the firm's premises.
- Responsive desktop/tablet/mobile navigation and layouts.
- Audit, Income Tax, GST, Accounting, Corporate/MCA and Business Advisory services.
- Current 2026 regulatory insight cards linked to official government portals.
- Government/professional portal links: Income Tax, GST, MCA, EPFO, Udyam and ICAI.
- Google Maps links for each branch.
- Legal note that the ABVPK & Associates name remains subject to applicable ICAI approval/registration as stated in the supplementary deed.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Before production launch
1. Connect the enquiry form to the firm's email/CRM endpoint.
2. Replace illustrative branch photography with actual office photographs when available.
3. Add the firm's final public phone/email/WhatsApp details.
4. Add the final approved firm logo and any approved ICAI/firm registration details.
5. Confirm the public firm name after applicable ICAI approval/registration.
